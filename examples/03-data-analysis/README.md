# مثال ۳ — آزمون محلیِ ایمنی و محاسبه بر داده ساختگی

این مثال صرفاً نشان می‌دهد چگونه آمار توصیفی کوچک به‌صورت تکرارپذیر محاسبه، ذخیره و در آزمون بازاجرا می‌شود. داده‌های `synthetic-data.csv` مصنوعی‌اند و نتیجه هیچ مطالعه‌ای نیستند.

اجرا از ریشه مخزن:

```bash
python tools/demo_analysis.py
python -m unittest discover -s tests -v
```

**مرز مهم:** موفقیت این اسکریپت، کارکرد ChatGPT Work یا اعتبار علمی روش تحلیل را اثبات نمی‌کند.
