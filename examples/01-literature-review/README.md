# مثال ۱ — مروری آموزشی بر سه رکورد *کاملاً ساختگی*

پرسش نمونه: «آیا در نمونه‌های فرضی، یادآورهای کوتاه با تکمیل فعالیت مرتبط‌اند؟» این مثال هیچ شاهد تجربی و هیچ نتیجه پژوهشی درباره موضوع ارائه نمی‌کند؛ برای تمرین ثبت شواهد است.

- `records.csv`: نام‌ها و اعداد ساختگی؛ شناسه‌های EX- فقط برای آموزش هستند و DOI نیستند.
- `expected-review.md`: نشان می‌دهد چرا یک رکورد فقط خلاصه و یک رکورد متعارض باید HOLD بماند.
- مراحل مناسب: `W01→W03→W04→W05→W06`؛ در این مثال جست‌وجوی واقعی اینترنت انجام نشده است.

**معیار موفقیت:** مورد `EX-02` بدون متن کامل نباید به عنوان شاهد جزئیات روش‌شناختی تأیید شود؛ تعارض `EX-03` باید گزارش شود.
