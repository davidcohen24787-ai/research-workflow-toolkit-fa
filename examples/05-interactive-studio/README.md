# سناریوی نمایشی برای سازندهٔ تعاملی

**تمام اطلاعات این مثال آموزشی هستند؛ آزمون میدانی انسانی نیستند.**

۱. صفحه `docs/index.html` را باز کنید. ۲. عنوان «بررسی نمونه اثر بازخورد آموزشی» را وارد کنید. ۳. مسیر «پژوهش مفهومی و نظری» را انتخاب کنید. ۴. `W02` را به‌عنوان مرحله اختیاری بیفزایید. ۵. در حالت «یک Chat» فایل JSON را دریافت کنید.

**انتظار:** دقیقاً ۸ مرحله به ترتیب `W01, W02, W03, W05, W06, W10, W11, W12`؛ تمام وظایف QUEUED؛ هیچ تأیید انسانی خودکار صادر نشده، و هیچ داده‌ای به سرور ارسال نشده است. خود صفحه و تست `tests/test_studio.cjs` این قرارداد اجرایی را وارسی می‌کنند.

**آزمون خطا:** عنوان را پاک کنید؛ تولید فایل باید متوقف شود و پیام معتبرسازی دیده شود. با تغییر شیوه اجرا، پیش‌نمایش قبلی نامعتبر شده و باید دوباره ساخته شود.

این آزمایش، **درستیِ برنامه‌ریزی ماشینی** را می‌سنجد و درباره ارزش علمی یا میزان رضایت پژوهشگران حکمی صادر نمی‌کند.
