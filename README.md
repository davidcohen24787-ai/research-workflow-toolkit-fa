# جعبه‌ابزار آزاد گردش‌کار پژوهش با هوش مصنوعی | نسخه ۰.۲

**Research Workflow Toolkit — Persian-first**  
**وضعیت:** Candidate release / نسخه آزمایشی ساختاری | ۱۴ اکتبر ۲۰۲۶

این مجموعه **راهنمای ساخت گردش‌کار اختصاصی پژوهش** است، نه عامل خودکاری که ادعای انجام واقعی تمام مراحل تحقیق را داشته باشد. برای یک پژوهشگر بدون برنامه‌نویسی، یک گروه با Chatهای مستقل، یا محیط عامل‌محورِ مجهز قابل استفاده است.

## از کجا شروع کنم؟

1. [راهنمای انتخاب مسیر](docs/01-start-here.md) را بخوانید.
2. از [نقشه ۱۲ گردش‌کار](docs/02-research-lifecycle.md) مرحله مناسب را انتخاب کنید؛ همه مراحل برای همه پژوهش‌ها اجباری نیستند.
3. فایل `[Wxx].md` همان مرحله را کپی و متغیرهای داخل `[ ]` را پر کنید.
4. از [قالب Job Card](templates/job-card.md) و [Manifest](templates/manifest.json) برای ثبت وضعیت استفاده کنید.
5. برای اجرای محلی: `python tools/validate.py` و `python -m unittest discover -s tests -v`. برای شروع یک پروژه از روی مسیر آماده: `python tools/new_project.py --recipe conceptual --project "عنوان پژوهش" --output manifest.json`.

## چه چیزهایی آماده شده‌اند؟

- **۵ مسیر آماده متناسب با نوع پژوهش** در [recipes](recipes/): نظری، مرور نظام‌مند، کمی، کیفی و محاسباتی.
- **۱۲ گردش‌کار مرحله‌محور**: مسئله تا انتشار، هر کدام Markdown انسانی و JSON قابل‌اعتبارسنجی.
- **۳ نوع اجرا**: یک Chat، چندChat با نظارت، عامل‌محور مشروط.
- **قالب‌های اجرایی**: وظیفه، سند وضعیت، ثبت شاهد، داوری، تیکت اصلاح، بسته انتقال، دفتر جست‌وجو، گزارش تحلیل.
- **نمونه‌های آموزشی**: سه مثال کاملاً ساختگی، به‌علاوه یک فیش‌برداری واقعی از مقاله دانشگاهی بازخوانی‌شده، همراه با حدود دلالت.
- **ابزار سادهٔ محلی** برای ساخت Manifest و اعتبارسنجی ساختار؛ بدون اتصال به ChatGPT، Work یا GitHub API.
- **آزمون‌ها و CI** برای ساختار فایل‌ها و دروازه تأیید انسانی؛ بدون ادعای ممیزی علمی خودکار.

## یک مثال انتخاب

- رساله مفهومی/نظری: `W01→W03→W05→W06→W10→W11→W12`، در صورت لزوم با `W02`.
- مرور نظام‌مند: `W01→W02→W03→W04→W05→W06→W10→W11→W12` و انتخاب راهنمای گزارش متناسب.
- پژوهش کمی/تجربی: `W01→W02→W07→W08→W09→W10→W11→W12`؛ اخذ تأییدهای اخلاقی لازم پیش از کار با مشارکت‌کنندگان.

## حد و مرز

ادعاهای منبع علمی صرفاً از مواد واقعاً خوانده‌شده استخراج شوند. داوری همان Chat، «داوری مستقل» نیست. هیچ خروجی صرفِ حضور در یک فایل به وضعیت ACCEPTED ارتقا نمی‌یابد. اجرای خودکار و عمل در حساب‌ها بسته به مجوز، پلتفرم و آزمون واقعی محدود است. داده‌ها و محتوای شخصی هیچ‌وقت به‌صورت پیش‌فرض منتشر نمی‌شوند.
