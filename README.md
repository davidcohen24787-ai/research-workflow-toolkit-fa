# جعبه‌ابزار آزاد گردش‌کار پژوهش با هوش مصنوعی | نسخه ۰.۳ آزمایشی

**Research Workflow Toolkit — Persian-first**  
**وضعیت:** v0.3.0-rc1 — ابزار تعاملی قابل‌آزمون؛ بدون ادعای تأیید علمی یا pilot عامل‌محور | ۱۴ اکتبر ۲۰۲۶

این مجموعه **راهنمای ساخت گردش‌کار اختصاصی پژوهش** است، نه عامل خودکاری که ادعای انجام واقعی تمام مراحل تحقیق را داشته باشد. برای یک پژوهشگر بدون برنامه‌نویسی، یک گروه با Chatهای مستقل، یا محیط عامل‌محورِ مجهز قابل استفاده است.

## ادامه‌دادن پژوهش و ثبت پیشرفت (نسخه ۰.۳.۱ آزمایشی)

پس از ساختن برنامه و دریافت فایل `research-manifest.json`، در **[میزکار پیشرفت پژوهش](docs/run.html)** فایل را وارد کنید. می‌توانید آغاز مأموریت، نشانی خروجی، بازبینی و پذیرش دستی، توقف‌ها و ادامه از فایل وضعیت را مدیریت کنید. **این میزکار عامل پژوهشی نیست، منبع را تأیید نمی‌کند و به ChatGPT/Work دسترسی مستقیم ندارد.** بعد از هر تغییر، فایل جدید را دانلود کنید؛ ذخیره خودکار یا ارسال داده به سرور وجود ندارد. [راهنمای استفاده و محدودیت‌ها](docs/12-run-workbench.md).

## یک راه بسیار ساده: طراحی گردش‌کار بدون برنامه‌نویسی

**طراح تعاملی گردش‌کار پژوهش** — بدون حساب، بدون کلید API و بدون ارسال داده به سرور. برای اجرای آفلاین، از دکمه سبز `Code` گزینه `Download ZIP` را انتخاب کنید، فایل ZIP را باز کنید و روی `docs/index.html` دوبار کلیک کنید. [مشاهده فایل طراح (نمایش کد در GitHub)](docs/index.html). از میان پنج نوع مطالعه یا دوازده مرحله، یک مسیر را انتخاب کنید و **Manifest JSON، راهنمای Markdown و Job Card مأموریت اول** را در مرورگر تولید و دریافت کنید. فایل‌ها در خود مرورگر ساخته می‌شوند و پژوهش، داوری یا انتشار خودکار انجام نمی‌شود.

برای اجرای مستقیم در اینترنت، باید GitHub Pages از شاخه `main` و پوشه `/docs` فعال شود؛ بازکردن HTML در نمای GitHub به‌تنهایی برنامه را اجرا نمی‌کند. **تا پیش از تأیید تنظیم و لینک زنده، این ادعا را عملیاتی تلقی نکنید.** راهنمای فنی: [استودیو](docs/10-studio-guide.md).

## از کجا شروع کنم؟

1. [راهنمای انتخاب مسیر](docs/01-start-here.md) را بخوانید.
2. از [نقشه ۱۲ گردش‌کار](docs/02-research-lifecycle.md) مرحله مناسب را انتخاب کنید؛ همه مراحل برای همه پژوهش‌ها اجباری نیستند.
3. فایل `[Wxx].md` همان مرحله را کپی و متغیرهای داخل `[ ]` را پر کنید.
4. از [قالب Job Card](templates/job-card.md) و [Manifest](templates/manifest.json) برای ثبت وضعیت استفاده کنید.
5. برای اعتبارسنجی محلی: `python tools/validate.py`، `python tools/generate_studio_catalog.py --check`، `python -m unittest discover -s tests -v` و `node --test tests/test_studio.cjs`. برای شروع یک پروژه از روی مسیر آماده: `python tools/new_project.py --recipe conceptual --project "عنوان پژوهش" --output manifest.json`.

## چه چیزهایی آماده شده‌اند؟

- **سازندهٔ تعاملی فارسی (آزمایشی):** انتخاب مسیر، ریسک و شیوه اجرا، نمایش مراحل، صدور برنامه پژوهش و دستور شروع؛ قابل اجرا از روی فایل دانلودشده.
- **هماهنگی فنی:** تعریف‌های JSON منبع واحد هر دو موتور Python و JavaScript هستند؛ تطابق آن‌ها در آزمون مستقل کنترل می‌شود.

- **۵ مسیر آماده متناسب با نوع پژوهش** در [recipes](recipes/): نظری، مرور نظام‌مند، کمی، کیفی و محاسباتی.
- **۱۲ گردش‌کار مرحله‌محور**: مسئله تا انتشار، هر کدام Markdown انسانی و JSON قابل‌اعتبارسنجی.
- **۳ نوع اجرا**: یک Chat، چندChat با نظارت، عامل‌محور مشروط.
- **قالب‌های اجرایی**: وظیفه، سند وضعیت، ثبت شاهد، داوری، تیکت اصلاح، بسته انتقال، دفتر جست‌وجو، گزارش تحلیل.
- **نمونه‌های آموزشی**: سه مثال کاملاً ساختگی، به‌علاوه یک فیش‌برداری واقعی از مقاله دانشگاهی بازخوانی‌شده، همراه با حدود دلالت.
- **ابزار سادهٔ محلی** برای ساخت Manifest و اعتبارسنجی ساختار؛ بدون اتصال به ChatGPT، Work یا GitHub API.
- **آزمون‌ها و CI** برای ساختار فایل‌ها و دروازه تأیید انسانی؛ بدون ادعای ممیزی علمی خودکار.

## یک مثال انتخاب

- رساله مفهومی/نظری: `W01→W03→W05→W06→W10→W11→W12`، در صورت لزوم با `W02`.
- مرور نظام‌مند: `W01→W02→W03→W04→W05→W06→W10→W11→W12` و انتخاب راهنمای گزارش متناسب.
- پژوهش کمی/تجربی: `W01→W02→W07→W08→W09→W10→W11→W12`؛ اخذ تأییدهای اخلاقی لازم پیش از کار با مشارکت‌کنندگان.

## حد و مرز

ادعاهای منبع علمی صرفاً از مواد واقعاً خوانده‌شده استخراج شوند. داوری همان Chat، «داوری مستقل» نیست. هیچ خروجی صرفِ حضور در یک فایل به وضعیت ACCEPTED ارتقا نمی‌یابد. اجرای خودکار و عمل در حساب‌ها بسته به مجوز، پلتفرم و آزمون واقعی محدود است. داده‌ها و محتوای شخصی هیچ‌وقت به‌صورت پیش‌فرض منتشر نمی‌شوند.
