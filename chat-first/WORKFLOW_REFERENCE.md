# فهرست کوچک مسیرهای پژوهش و حدود هر مرحله — نسخهٔ عمومی و قابل‌حمل

**راهنمای مرجع، نه اثبات علمی**. اگر توضیح دقیق یک مرحله در `workflows/Wxx.md` و JSON متناظر موجود باشد، آن سند معتبرتر از خلاصه حاضر است. مدل نباید صرفاً از روی این فهرست ادعای خواندن منبع اصلی کند.

## پنج مسیر شروع پیشنهادی

- **نظری/مفهومی:** W01 → W03 → W05 → W06 → W10 → W11 → W12؛ W02 در صورت نیاز.
- **مرور نظام‌مند:** W01 → W02 → W03 → W04 → W05 → W06 → W10 → W11 → W12؛ انتخاب دستورالعمل گزارش‌دهی متناسب.
- **کمی/تجربی:** W01 → W02 → W07 → W08 → W09 → W10 → W11 → W12؛ تایید اخلاقی و روش‌شناختی لازم.
- **کیفی:** W01 → W02 → W07 → W08 → W09 → W10 → W11 → W12؛ W09 را به تحلیل کیفی متناسب تبدیل کنید.
- **محاسباتی:** W01 → W02 → W03 → W05 → W06 → W07 → W08 → W09 → W10 → W11 → W12.

پژوهشگر یک مرحله منفرد یا مجموعه سفارشی نیز برمی‌گزیند؛ هیچ مسیر ثابتی برای همه رشته‌ها الزام‌آور نیست.

## چهار نمونه گردش‌کار پژوهشی داخل چت

**بررسی یک مقاله**: متن/صفحه موجود → W05 استخراج اولیه → نقد همان چت در گذر دوم → پالایش در گذر سوم → بررسی مستقل در چت دیگر *در صورت نیاز* → گزارش محدوده شواهد.

**مرور ادبیات**: W01 سوال‌ها → W02 پروتکل → W03 رشته‌های جست‌وجو → W04 غربال → W05 استخراج → W06 سنتز. اگر ابزار جست‌وجو در دسترس نیست، فقط طرح جست‌وجو بده، نه نتایج خیالی.

**نگارش پژوهشی**: دو پیش‌نویس مفهومی متفاوت، نقد و انتخاب، دریافت شواهد احرازشده، نگارش مستند، ممیزی استناد و ویرایش فهم‌پذیری، سپس تایید نویسنده. تعداد مراحل باید متناسب با ریسک باشد؛ برای برنامه تفصیلی [`profiles/WRITING_13_STAGE.md`](profiles/WRITING_13_STAGE.md) را بخوانید.

**نقد چندگفت‌وگویی**: نسخه مبنا قفل؛ نقدهای واقعاً جدا؛ داوری ایرادها بر اساس شواهد و معیار نه رای اکثریت؛ تیکت تغییر؛ بازبینی diff؛ تصویب پژوهشگر.

## احراز سند و تصمیم

- `VERIFIED_FULLTEXT`: بخش مرتبط از نسخه اصلی واقعاً خوانده شده؛ مکان‌یاب دقیق.
- `ABSTRACT_LIMITED`: چکیده رسمی، ادعای محدود به متن چکیده و محدودیت روشن.
- `UNREAD`: هنوز برای ادعای علمی استفاده نشود.
- `USER_PROVIDED_UNCHECKED`: ادعای/فایل ارائه‌شده ولی صحت یا نسخه احراز نشده.

وضعیت‌های کار: `QUEUED`, `IN_PROGRESS`, `UNDER_REVIEW`, `NEEDS_FIX`, `BLOCKED`, `ACCEPTED`. درخواست «تأیید» بدون ذکر خروجی و نسخه معتبر، تأیید همه پروژه نیست. فقط پژوهشگر انسانی اجازه انتشار، حذف مخرب، تصویب قطعی علمی یا اقدام اخلاقی حساس دارد.
