# دستیار پژوهشی گفت‌وگومحور، بدون API — نسخه ۰.۴ آزمایشی

**مسیر اصلی پروژه، خودِ ChatGPT یا Gemini است؛ سایت اجباری نیست.** پژوهشگر با امکانات اشتراک یا دسترسی فعلی خود، یک گفت‌وگوی معمولی را به «هماهنگ‌کننده پژوهش» تبدیل می‌کند. هیچ توکن API، سرور، عامل بیرونی، یا اتصال حساب دیگری لازم نیست.

## شروع کمتر از پنج دقیقه

**ChatGPT Plus:** در ChatGPT یک Project تازه برای *پژوهش خودتان* بسازید (یا یک Project موجود را استفاده کنید). متن [`platforms/CHATGPT_PROJECT.txt`](platforms/CHATGPT_PROJECT.txt) را در Project instructions قرار دهید. دو فایل [`WORKFLOW_REFERENCE.md`](WORKFLOW_REFERENCE.md) و [`COMMON_PROTOCOL.md`](COMMON_PROTOCOL.md) را به‌عنوان فایل مرجع Project بیفزایید. یک Chat عادی داخل همان Project آغاز کنید و بگویید «شروع پژوهش: [موضوع]؛ نوع پژوهش: [نوع]». اگر تنظیم دستورالعمل Project در حساب شما در دسترس نیست، متن را در ابتدای یک چت معمولی قرار دهید. **از پروژه پژوهشی دارای فایل‌های خصوصی، کپی عمومی نسازید.**

**Gemini:** یک Chat معمولی تازه باز کنید، متن [`platforms/GEMINI_CHAT.txt`](platforms/GEMINI_CHAT.txt) را به‌عنوان پیام نخست ارسال کنید و دو فایل [`WORKFLOW_REFERENCE.md`](WORKFLOW_REFERENCE.md) و [`COMMON_PROTOCOL.md`](COMMON_PROTOCOL.md) را ضمیمه کنید یا متن آن‌ها را در چت قرار دهید. استفاده از Gem یا Skills فقط گزینه تکمیلی و وابسته به امکانات روز حساب است؛ این روش به آن‌ها وابسته نیست.

**ادامه:** از دستیار بخواهید «مرحله بعد» یا «بسته انتقال»؛ برای رفتن به مدل دیگر، بسته انتقال را کپی و همراه با منابع لازم در چت مقصد قرار دهید. کیفیت و درستی حالت به همان شواهد واقعیِ ارائه‌شده وابسته است؛ **حافظه مشترک خودکار بین دو شرکت وجود ندارد**.

## دستورات کوتاه

| دستور محاوره‌ای | رفتار مورد انتظار |
|---|---|
| «پژوهش جدید: ...» | انتخاب مسیر و توضیح دامنه/پرسش و تصمیم لازم |
| «مرحله بعد» | فقط مرحله آماده اجرا با ورودی معتبر را اجرا کند |
| «وضعیت پژوهش» | فهرست کارهای پذیرفته، معلق، نامعلوم و اقدام بعدی |
| «نقد مستقل» | نقد توسط گفت‌وگوی دیگری را پیشنهاد دهد؛ نقد خودش را مستقل ننامد |
| «بسته انتقال» | پرونده قابل‌کپی با شاهد، تصمیم و محدودیت بسازد |
| «ادامه از بسته انتقال زیر: ...» | وضعیت را با بررسی اختلاف/نسخه بازیابی کند |
| «تأیید می‌کنم: ...» | فقط همان خروجی و نسخه را پس از مشخص‌شدن مرجع تصویب کند |

## ارزش و محدودیت

این یک **قرارداد مدیریت درون‌چت** است؛ ممکن است درستی دستورها به قابلیت مدل، ابزارهای متصل و طول گفت‌وگو وابسته باشد. اگر ابزار فایل، اینترنت یا ذخیره ندارید، مدل نباید ادعا کند به فایل دست یافته یا آن را واقعاً ذخیره کرده است. هیچ عامل خودکارِ پنهانی بین ChatGPT و Gemini راه‌اندازی نمی‌شود. در استفاده شدید ممکن است محدودیت اشتراک اعمال شود، ولی **هزینه API اضافی از طرف این بسته ایجاد نمی‌شود**.

بستهٔ عمومی خالی از داده کاربران است. برای پژوهش واقعی، فایل‌ها و موضوعات خصوصی را فقط به حساب خود و با رعایت سیاست‌های محرمانگی ارسال کنید.
