# تیکت داوری و اصلاح کنترل‌شده

- شناسه: `[REV-001]`
- وضعیت: `ACCEPT / HOLD / REJECT`
- محل دقیق و نسخه baseline: `[ ]`
- نقل عبارت مسئله‌دار (کوتاه): `[ ]`
- شاهد یا معیار مخالف: `[ ]`
- اهمیت/ریسک: `[ ]`
- اقدام مجاز: `ADD / REMOVE / REPLACE / NO_CHANGE`
- متن/حد تغییر: `[ ]`
- چیزهایی که نباید تغییر کنند: `[ ]`
- داور/تاریخ: `[ ]`
- ارزیابی پس از diff: `[ ]`

رأی اکثریت به تنهایی مبنای ACCEPT نیست. بدون تیکت دقیق، ویرایش خودکار متوقف شود.
