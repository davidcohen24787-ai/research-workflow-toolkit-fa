# ارزیابی گردش‌کارها

## پیش از ادعای اثربخشی

یک خط مبنا ثبت کنید: انجام همان کار در یک Chat ساده یا به‌صورت دستی. سپس روی مسائل هم‌ارز، بدون تغییر معیارها، مقایسه کنید.

| شاخص | تعریف سنجش | خطای متداول |
|---|---|---|
| پوشش | پرسش‌های اصلی پاسخ‌داده‌شده / پرسش‌های لازم | شمار مراحل را جانشین پوشش نکنید |
| صحت شاهد | ادعاهای قابل تطبیق با متن واقعاً خوانده‌شده / ادعاهای نمونه‌گیری‌شده | DOI به‌تنهایی صحت نیست |
| خطای منبع | ادعا/صفحه/نقل قول بدون شاهد واقعی | نمونه‌های ساختگی را یافته علمی ننامید |
| تعارض حل‌شده | موارد داوری‌شده همراه دلیل و مرجع | رأی اکثریت بدون دلیل کافی نیست |
| زمان و هزینه | زمان صرف‌شده انسانی و ماشینی / خروجی پذیرفته | تعداد Chat را شاخص کیفیت ندانید |
| نرخ پذیرش | تحویل پذیرفته‌شده / تلاش‌های واقعی | وضعیت خوداظهاری کافی نیست |
| بازتولید | اجرای دوباره با داده، کد و نسخه ثابت | اجرای فقط یک‌بار کافی نیست |
| دخالت انسانی | تصمیم‌های پرخطر تأییدشده / کل تصمیم‌های پرخطر | انتشار بدون تأیید شکست است |

## پروتکل آزمایش کوچک

برای هر الگو: سه مأموریت کوچک با معیارهای ثابت انتخاب، خطاها ثبت، خروجی توسط یک ارزیاب انسانی با متن اصلی سنجیده و توقف‌ها گزارش شود. سناریوهای بدون متن کامل، اختلاف داوران و قطع دسترسی را هم وارد کنید. تنها پس از آزمون واقعی، درصد عملکرد و نام محیط اجرا اعلام شود.
