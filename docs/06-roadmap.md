# نقشه تکامل

## v0.2 — اکنون

۱۲ قالب مرحله‌محور + ۵ مسیر پژوهشی آماده + ساختار JSON، ۳ حالت اجرا، کتابچه فارسی، قالب‌های اجرای امن، سه مثال آموزشی مصنوعی، ابزار ساده ایجاد Manifest و اعتبارسنجی ماشینی.

## v0.3 — پس از سنجش

سازنده تعاملی گردش‌کار (انتخاب نوع مطالعه/ریسک/ابزار)؛ خروجی آماده Chat، Work یا فایل Manifest؛ مقایسه نسخه‌های گردش‌کار؛ چند pilot واقعی با معیارهای اندازه‌گیری‌شده، بدون جعل.

## v0.4 — پس از بازخورد جامعه

نسخه دوزبانه، رجیستری الگوها، امکان ثبت نمونه‌های تکرارپذیر توسط کاربران، سیاست ارجاع نسخه‌دار و پیشنهادهای بهبود بر مبنای آزمون‌ها. ابزار تحت وب از موتور نسخه‌دار ساخته می‌شود؛ منطق علمی به UI وابسته نمی‌ماند.

## شرط انتشار عمومی

بازبینی محرمانگی و حق نشر، تعیین انتساب و مجوز، تکمیل تست‌ها، ایجاد مخزن مستقل **بدون اتصال به مخزن خصوصی پروژه پژوهشگر** و سپس فعال کردن Template Repository با دسترسی مدیر.

## پس از انتشار

برای استناد نسخه‌دارِ دانشگاهی، پس از تأیید نام صاحب اثر و اطلاعات CITATION.cff و انتشار مخزن، اتصال GitHub به Zenodo و ثبت Release عمومی بررسی شود. شناسه DOI را تا وقتی واقعاً صادر نشده در فایل‌ها درج نکنید.
