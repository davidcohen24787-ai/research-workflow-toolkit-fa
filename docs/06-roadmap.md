# نقشه تکامل

## v0.3.0-rc1 — اکنون

نسخه آزمایشی طراح تعاملی فارسی، خروجی Manifest/Job Card و آزمون همسانی گراف وظایف Python/JavaScript. اعتبارسنجی فنی انجام شده، اما آزمون میدانی با انسان و اجرای واقعی Work/چندChat انجام نشده‌اند.

## v0.3 — برای تثبیت پس از آزمون انسانی

تکمیل مطالعه تجربی با خط مبنا، آزمون دسترس‌پذیری، سنجش پژوهشگر غیرمتخصص و رفع خطاهای واقعی. انتشار نسخه پایدار فقط بعد از این دروازه‌ها.

## v0.4 — توسعه جامعه

مسیرهای اختصاصی رشته‌ها، نمونه‌های تکرارپذیرِ قابل‌داوری، نسخه دوزبانه دقیق و نسخه‌بندی مستند.

## شرط انتشار عمومی

بازبینی محرمانگی و حق نشر، تعیین انتساب و مجوز، تکمیل تست‌ها، ایجاد مخزن مستقل **بدون اتصال به مخزن خصوصی پروژه پژوهشگر** و سپس فعال کردن Template Repository با دسترسی مدیر.

## پس از انتشار

برای استناد نسخه‌دارِ دانشگاهی، پس از تأیید نام صاحب اثر و اطلاعات CITATION.cff و انتشار مخزن، اتصال GitHub به Zenodo و ثبت Release عمومی بررسی شود. شناسه DOI را تا وقتی واقعاً صادر نشده در فایل‌ها درج نکنید.
