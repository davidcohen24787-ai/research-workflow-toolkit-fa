# معیارهای بیرونی مرتبط و حد استفاده

این فهرست **پشتوانهٔ خودکار بودن گردش‌کارهای این مخزن نیست**؛ صرفاً استانداردهای بیرونی مرتبط را برای انتخاب روش و شفافیت معرفی می‌کند.

1. Page et al. (2021). *The PRISMA 2020 statement: an updated guideline for reporting systematic reviews.* BMJ, 372, n71. https://doi.org/10.1136/bmj.n71 — برای **گزارش مرورهای نظام‌مند**، نه الزام همگانیِ هر مرور.
2. Wilkinson et al. (2016). *The FAIR Guiding Principles for scientific data management and stewardship.* Scientific Data, 3, 160018. https://doi.org/10.1038/sdata.2016.18 — یافت‌پذیری، دسترس‌پذیری، تعامل‌پذیری و بازاستفاده از داده/فرایندهای پژوهش.
3. W3C (2013). *PROV-O: The PROV Ontology.* https://www.w3.org/TR/prov-o/ — مدلی عمومی برای ثبت منشأ؛ نام این استاندارد دلیل پیاده‌سازی واقعی آن در ابزارهای ما نیست.
4. EQUATOR Network. Reporting guideline library. https://www.equator-network.org/library/ — راهنمای انتخاب گزارش‌نویسی متناسب با نوع مطالعه (مثلاً CONSORT، STROBE، SRQR، COREQ، PRISMA).
5. GitHub Docs. *Creating a template repository.* https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository — ساخت مخزن الگو بعد از ایجاد مخزن.

از راهنمای گزارش‌دهی، روش مطالعه یا استاندارد انتساب یک استنتاج علمی جدید دربارهٔ کارایی AI نتیجه نگیرید.
